# 🚀 TaskFlow - Professional Task Manager

TaskFlow is a modern and responsive task management web application built using HTML, CSS and JavaScript.

It allows users to create, manage, organize and track their daily tasks with priorities, categories, tags, deadlines, search, filters, sorting and productivity statistics.

## ✨ Features

### 📝 Task Management

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View pending tasks
- View completed tasks

### 🎯 Task Priority

Tasks can be assigned different priority levels:

- 🔴 High
- 🟡 Medium
- 🟢 Low

### 📅 Due Date Management

- Set task deadlines
- View upcoming deadlines
- Detect overdue tasks
- Highlight tasks due today
- Show completed task status

### 🏷️ Categories

Tasks can be organized using categories such as:

- 📚 Study
- 💼 Work
- 👤 Personal
- 🏠 Other

### 🔖 Tags

Tasks can contain multiple tags.

Example:

```text
#javascript
#frontend
#coding
